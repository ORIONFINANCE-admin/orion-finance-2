ORION FINANCE v0.1 — COMECE AQUI
================================

1. Esta é uma versão NOVA do Orion.
   Não substitui dados do 0.14.x por migração. Ela começa vazia.

2. Para o GitHub Pages:
   - substitua o conteúdo do repositório pelos arquivos desta pasta;
   - faça commit/push;
   - abra https://SEU-USUARIO.github.io/SEU-REPO/mobile/

3. Abra uma vez com internet antes de testar offline.

4. No primeiro uso:
   - Início > + Conta;
   - cadastre somente as contas e os saldos que existem HOJE;
   - a partir daí registre apenas os movimentos novos.

5. Para Maria Estela:
   - Mais > Perfis financeiros > Criar perfil;
   - Planejar > + Objetivo;
   - selecione Maria Estela e a conta física onde o dinheiro ficará;
   - depois, no card, Aportar;
   - você informa somente o valor.

6. Google Sheets é opcional.
   O Orion funciona localmente sem ele.
   Para sincronizar, siga backend/INSTALACAO.txt.

7. Recomendação forte:
   crie uma NOVA planilha Google Sheets para esta v0.1.

8. O app sincroniza automaticamente ao abrir e ao recuperar conexão.
   O botão de sync serve apenas como controle/forçar tentativa.
