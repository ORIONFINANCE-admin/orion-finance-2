ORION FINANCE v0.2 — INSTALAÇÃO

1. Publique o conteúdo desta pasta em hospedagem HTTPS (ex.: GitHub Pages).
2. Abra /mobile/ pelo Safari no iPhone.
3. Compartilhar > Adicionar à Tela de Início.
4. Abra uma vez com internet para que o Service Worker armazene a interface do app.
5. Depois disso, os dados financeiros funcionam localmente no aparelho por IndexedDB.

IMPORTANTE
- Não existe conexão com Google Sheets nesta versão.
- Não há conta remota, token ou endpoint de sincronização.
- Use Configurações > Exportar backup periodicamente.
- Antes de apagar dados do Safari/site, exporte um backup JSON.
