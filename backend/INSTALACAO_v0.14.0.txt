ORION FINANCE 2.0 — INSTALAÇÃO SEGURA v0.14.0
==============================================

IMPORTANTE
----------
A v0.14.0 altera o schema de 1.8.0 para 1.9.0.
Ela NÃO reescreve CONTAS, TRANSACOES ou TRANSFERENCIAS existentes.
As novas estruturas são criadas em abas separadas.

ARQUIVO
-------
Use:
Orion_Finance_2.0_AppsScript_v0.14.0.txt

PASSO A PASSO
-------------
1. Abra o Apps Script ligado à planilha Orion.
2. Faça uma cópia manual do Code.gs atual se desejar uma referência adicional.
3. Substitua integralmente o Code.gs pelo conteúdo do arquivo v0.14.0.
4. Salve.
5. Execute:

   atualizarEstruturaOrionV19()

6. Autorize o script se o Google solicitar.
7. A migração cria automaticamente um BACKUP COMPLETO em outra planilha ANTES de alterar a estrutura.
8. Confira o Log. O retorno esperado contém:

   ok: true
   schema_version: 1.9.0
   backup_url: ...

9. Reimplante o Aplicativo da Web usando uma NOVA VERSÃO da implantação.
10. Publique o frontend v0.14.0 no GitHub Pages.

O QUE A MIGRAÇÃO CRIA
---------------------
PERFIS
ALOCACOES
MOVIMENTOS_ALOCACAO

Também cria, se ainda não existir:
perfil_principal / João / pessoal

O QUE ELA NÃO FAZ
-----------------
- não apaga histórico;
- não limpa TRANSACOES;
- não altera IDs históricos;
- não reimporta Jul/Ago 2026;
- não transforma transferências em receitas/despesas;
- não exige criar conta bancária para um dependente.

COMPATIBILIDADE
---------------
A antiga chamada atualizarEstruturaOrionV18() permanece como alias de compatibilidade,
mas para esta atualização use explicitamente atualizarEstruturaOrionV19().

ROLLBACK
--------
A infraestrutura de backup/restauração segura da v0.11.1 foi preservada.
O último backup automático continua registrado nas propriedades do Apps Script.

NÃO EXECUTE
-----------
Não execute importarConciliacaoJulAgo2026() para atualizar para v0.14.0.
Essa função é histórica e não faz parte desta migração.
