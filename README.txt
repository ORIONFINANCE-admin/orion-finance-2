ORION FINANCE v0.4.1 — LOCAL ONLY

Deploy:
1. Envie todo o conteúdo desta pasta mantendo /mobile e /assets.
2. Abra a raiz do site; index.html redireciona para /mobile/.
3. No iPhone, abra pelo Safari e use Compartilhar > Adicionar à Tela de Início.

Dados:
- IndexedDB: orion_finance_v01
- Sem Google Sheets, Apps Script ou backend remoto.
- Backup manual JSON disponível no menu do avatar J.

Atualização:
- Esta versão mantém o mesmo banco local para preservar os dados atuais.
- O service worker usa um novo cache v0.4.1 e remove caches Orion antigos na ativação.
