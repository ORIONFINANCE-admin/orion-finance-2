ORION FINANCE v0.3

Aplicativo financeiro pessoal PWA, mobile-first e 100% local.

ARMAZENAMENTO
Os dados são mantidos no IndexedDB do próprio navegador/aparelho. Não há conexão com Google Sheets ou backend remoto.

SEGURANÇA DOS DADOS
Use Conta e configurações > Exportar backup periodicamente. O Orion mostra a data do último backup e recomenda um novo após 7 dias. A importação valida o arquivo e gera uma cópia de segurança do estado atual antes de restaurar.

GESTÃO FINANCEIRA
A Home mostra caixa e próxima prioridade. A área Planejar separa patrimônio, reserva, dívidas, objetivos e fechamento mensal. Transferências não contam como receita/despesa; liquidação de fatura é neutra; pagamentos de dívida reduzem caixa e passivo, mas ficam separados das despesas de consumo.

INSTALAÇÃO
Publique a pasta completa em hospedagem HTTPS (por exemplo, GitHub Pages), abra /mobile/ pelo Safari no iPhone e escolha Compartilhar > Adicionar à Tela de Início.
